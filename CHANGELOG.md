# Changelog

All notable changes to PassGen.

## [1.1.0] - 2026-02-23

### Added
- **PWA Support** - Install as a standalone app on mobile/desktop
- **Custom Favicon** - SVG favicon with lock icon
- **Manifest** - Full app manifest for installability

---

## [1.0.0] - 2026-01-27

### Added
- **Initial Release**
- Configurable password length
- Character set options:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Symbols (!@#$%^&*)
- Visual password strength indicator
- One-click copy to clipboard
- Secure generation using `crypto.getRandomValues()`
- All generation happens locally (no server calls)
- Clean responsive UI
- Works offline
